# Design

- `system/`: brand, design tokens, motion language, components, accessibility and screen map (Phase 3, agent A6, DRIVE-99)
- `<JIRA-KEY>/<ios|android|web>/`: design artifacts for each ticket, generated by `prototypes/tools/export.mjs` and then `pack.mjs`:
  - `design-spec.md`: the developer's source of truth
  - `mockup.html`: a live contact sheet of the story's screens and states
  - `mockup.webp`: a screenshot of that contact sheet
  - `assets/`: icons and brand assets the screens use
- `screens/<ios|android|web>/`: the shared gallery of every screen and state, stored once as WebP and linked from each story's `design-spec.md`. Default app states are at device resolution (iOS 1206×2622, Android 1082×2402); other states are at 2×.

The interactive prototypes are in [`prototypes/`](../../prototypes/). Do not edit the generated files by hand: change the screen in `prototypes/app/screens/wp-*.js` and re-export.

Design artifacts from the Android prototype are in `legacy/android-prototype/docs/design/`.
