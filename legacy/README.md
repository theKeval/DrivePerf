# Legacy

`android-prototype/` is the frozen Android-only prototype (Kotlin, Jetpack Compose, Room, Hilt), formerly DriveStats. It is kept for reference: platform patterns, the permission flow and the earlier scoring experiments. Its score weights and features are **not** v1 requirements.

To build it, open `legacy/android-prototype/` in Android Studio. The same tree is also available at tag `android-prototype-v0`, where it sits at the repository root.
