# Prototypes

High-fidelity, clickable HTML/CSS/JS prototypes. They need no build step: open each `index.html` directly.

| Folder | Platform styling | Agent |
|---|---|---|
| `ios/` | iOS 26/27 Liquid Glass, HIG | A7 |
| `android/` | Material 3 Expressive | A8 |
| `web/` | driveperf.com landing site (informational) | A9 |

iOS and Android share the UX and the fixture data (`js/data.js`). Only the cosmetics differ by platform.
